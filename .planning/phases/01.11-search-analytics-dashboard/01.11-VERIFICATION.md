# Search analytics — verification (EXPLAIN plans + p95 latencies)

Corpus: **100k search_events rows spread across the 90-day retention window** + **10k result rows attached to events in the last 7 days** across 200 distinct pages.
Every plan below is captured against the same fixture-backed Postgres 17 container.
