Administrators can use every tool an editor can. These pages cover the rest: the shape of the site, moving content between environments, what people search for, and who has access.

## The Administration page

Select **Admin** in the header. The Administration page lists every tool your role can use, in groups. The same groups are in the menu on the left of every admin screen.

The CMS tools are in the **CMS administration** group.

| Tool | What it is for | Editors have it |
|---|---|---|
| Pages | Create, edit, move, copy and delete pages | Yes |
| Content blocks | Edit the text of the fixed pages | Yes |
| Deleted pages | Restore a page that was deleted | Yes |
| Content staging import/export | Move content between environments | Yes |
| Search analytics | See what people search for and cannot find | No |

Other tools that affect the CMS are in other groups: **System settings**, **Role settings**, **Site CSS and JavaScript** and **View logs** under *System administration*, **Search feedback** under *Messages*, and the **Audit log**.

"Editors have it" is the starting position. You can change it on the [Role settings](managing-roles.md) screen.

## A routine worth keeping

Once a month, or after any busy period:

1. Open **Search analytics** and read the top searches that found nothing. Each one is a page to write or a keyword to add.
2. Read new **Search feedback** and mark each note as read once someone has dealt with it.
3. Look through **Deleted pages** for anything deleted by mistake.
4. Check **Role settings** still matches who should have access.
