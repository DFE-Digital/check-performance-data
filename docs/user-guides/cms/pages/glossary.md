The words you will meet in the CMS and in this guide.

## Pages and their parts

| Word | What it means |
|---|---|
| Page | Something with an address on the public site that you create and manage in the CMS. |
| Content page | A page built from widgets. The usual kind. |
| Wiki page | A simpler page that holds one block of text and nothing else. |
| Folder | A container for pages. It has no content of its own. |
| Page tree | All the pages of the site, arranged by which page sits beneath which. |
| Parent, child | A page directly above another in the tree is its parent. The page beneath is its child. |
| Section | One of the 4 top-level pages the service creates: Support, Wiki, Help and Guidance. |
| URL segment | The last part of a page's address. In `/guidance/ks4-checking` it is `ks4-checking`. |
| Path | A page's whole address after the site name, such as `guidance/ks4-checking`. |
| Region | A row of a content page that sets how many columns it has. |
| Widget | One piece of content in a region, such as a heading, some text or a search box. |
| Content block | A piece of text on a page that is built into the service, such as the home page or the footer. |
| Key | The name of a content block, such as `home-content`. |

## Publishing

| Word | What it means |
|---|---|
| Draft | A version nobody outside the CMS can see yet. |
| Live, published | The version visitors see. |
| Scheduled | A version with a **Publish from** date in the future. |
| Past | A version that has been published and is not the live one now. |
| Version | A saved state of a page or content block. Every version is kept. |
| Publish from, Publish to | The start and end of the time a version is live. |
| Unpublish | Take the live version of a page off the public site without deleting it. |
| Revert | Make an earlier version of a content block the live one again. |
| UTC | The time standard the service uses. The same as UK time in winter, and one hour behind it in summer. |

## Search

| Word | What it means |
|---|---|
| Search keywords | Extra words you give a page so that it is found by them. |
| Instant search | A search box that suggests matches while you type. |
| Scope | The part of the site a search box looks in. |
| Zero-result search | A search that found nothing. |
| Session | One visit to the site. Searches are grouped by session, not by person. |

## Administration

| Word | What it means |
|---|---|
| Role | What kind of user you are. It is set in DfE Sign-in and decides what you can use. |
| Section (of the admin area) | One tool or group of tools that a role can be given access to. |
| Environment | One copy of the service. There are separate ones for development, testing and the real thing, which is called production. |
| Content staging | The tool for copying content from one environment to another. |
| Bundle | The zip file that Content staging exports and imports. |
| Audit log | The record of what people did in the admin area. |
