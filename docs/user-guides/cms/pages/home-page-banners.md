The start page can show one or more blue **Important** banners above its heading, for news
such as new rules, a known problem or an extended deadline. You manage them from
**CMS administration > Home page banners**.

## Create a banner

1. Select **Create a banner**.
2. Enter a **heading** (plain text, up to 200 characters) and the **banner text**. Links and
   lists are allowed. Keep it to a sentence or two.
3. Tick **Show this banner** when it is ready. Leave it unticked while you draft.
4. Optionally enter **Show from** and **Show until** dates and times, in UK time. Leave a
   date blank for no limit.
5. Select **Save banner**.

A banner is on the start page only while it is ticked **and** within its dates. "Show from"
includes the minute you enter; "Show until" does not.

## Order, status and preview

The list shows banners in the order they appear on the start page. Use **Move up** and
**Move down** to change it. Each banner shows a status: **Live**, **Scheduled** (not yet
due), **Expired** (past its end) or **Off**. **Preview** shows a banner as schools will
see it, whatever its status.

## Versions

Every save makes a new version. Open **Version history** to see them and to **Restore** an
earlier one. Restoring makes a copy of that version the newest; nothing is lost.

## Delete a banner

**Delete** asks you to confirm and cannot be undone. To hide a banner for a while, untick
**Show this banner** instead.

## Moving banners between environments

Banners go in the content staging export and import with their versions, under
**Home page banners** on the selection page.
